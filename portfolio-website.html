Overview

This project represents my very first foray into building a multi‑page website from scratch. The goal was to familiarise myself with core web technologies – HTML for structure, CSS for styling and basic JavaScript for interactivity – while creating a clean and responsive portfolio to showcase my work. The site you’re viewing now is a direct result of that learning journey.

Key highlights

Notable aspects of this mini project.

  • Built with semantic HTML, custom CSS and lightweight JavaScript for smooth navigation and dynamic effects.
  • Designed a responsive layout that adapts to desktop and mobile screens using CSS grid and flexbox.
  • Integrated icons, badges and custom components (e.g., cards and buttons) for a polished look.
  • Deployed the site using GitHub Pages, learning basic version control and workflow in the process.
